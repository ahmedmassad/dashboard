# Ledger

صفحة داشبورد شخصية لمتابعة الحسابات والمعاملات والأهداف والمهام. كل حاجة بتتحفظ في المتصفح نفسه، ومفيش سيرفر.

## الملفات

- `index.html`: الصفحة كلها (HTML وCSS وJavaScript في ملف واحد).
- `README.md`: الشرح ده.

## الرفع على GitHub Pages

1. اعمل repository جديد على GitHub، واسمه مثلاً `ledger`.
2. ارفع الملفين `index.html` و`README.md` فيه.
3. من **Settings** ← **Pages**، اختار الفرع `main` والمجلد `/ (root)`.
4. استنى دقيقة، والرابط هيكون `https://اسمك.github.io/ledger/`.

## أول مرة تفتح الصفحة

1. اكتب يوزرنيم وباسورد (8 حروف أو أكتر)، وكررهم للتأكيد.
2. اضغط **Create account**، وهتدخل الداشبورد.
3. من **Settings** ← **Example data** تقدر تحمّل بيانات تجريبية، وتمسحها واحدة واحدة.

## لو نسيت الباسورد

اضغط **Forgot password?** ثم **Reset password**. ده بيمسح اليوزرنيم والباسورد القديمين، وبياناتك بتفضل زي ما هي، وبتعمل حساب جديد.

## ملاحظات مهمة

- **البيانات في المتصفح ده بس**. لو مسحت بيانات المتصفح أو فتحت من جهاز تاني، هتبدأ من الأول.
- **الباسورد مش حماية حقيقية**: بيتحفظ كهاش في نفس المتصفح، فيحمي من الفضول بس، مش من حد وصل لجهازك.
- **مفيش إرسال بيانات لأي سيرفر**، كل حاجة بتتعمل محلياً.
