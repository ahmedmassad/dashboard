# Ledger

صفحة داشبورد شخصية لمتابعة الحسابات والمعاملات والأهداف والمهام. كل حاجة بتتحفظ في المتصفح نفسه، ومفيش سيرفر.


## أول مرة تفتح الصفحة

1. اكتب يوزرنيم وباسورد (8 حروف أو أكتر)، وكررهم للتأكيد.
2. اضغط **Create account**، وهتدخل الداشبورد.
3. من **Settings** ← **Example data** تقدر تحمّل بيانات تجريبية، وتمسحها 

## ملاحظات مهمة

- **البيانات في المتصفح ده بس**. لو مسحت بيانات المتصفح أو فتحت من جهاز تاني، هتبدأ من الأول.
- **الباسورد مش حماية حقيقية**: بيتحفظ كهاش في نفس المتصفح، فيحمي من الفضول بس، مش من حد وصل لجهازك.
- **مفيش إرسال بيانات لأي سيرفر**، كل حاجة بتتعمل محلياً.
